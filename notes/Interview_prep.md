# C++ 基础（10 题）

### unique_ptr 和 shared_ptr 的区别？
unique_ptr 是独占所有权智能指针，同一时刻只有一个 unique_ptr 拥有对象，不可拷贝，但可以移动，
移动后原指针为空。它默认几乎没有额外运行时开销
shared_ptr 是共享所有权智能指针，通过控制块维护强引用计数和弱引用计数。
拷贝会增加强引用计数，最后一个强引用销毁时释放被管理对象；弱引用计数为 0 时释放控制块。有开销

### weak_ptr 解决什么问题？
主要解决 shared_ptr 的循环引用导致内存泄漏问题
例如 A 持有 shared_ptr<B>，B 持有 shared_ptr<A>，外部引用释放后两者强计数都不为 0，对象无法释放。
把其中一方改成 weak_ptr，它不增加强引用计数，打破循环

### 移动构造为什么 noexcept
异常安全和性能。移动后源对象状态已被改变，若移动过程中抛异常，无法恢复到移动前，容器扩容时就无法提供强异常安全保证。
vector 等容器在 move_if_noexcept 策略下，若移动构造不是 noexcept 且类型可拷贝，会退化为拷贝。
标 noexcept 等于告诉标准库“可以放心 move”，从而走移动、提升性能。移动构造不该抛异常。

### 虚函数怎么实现？虚函数表存在哪？
含虚函数的类，编译期为每个类生成一张虚函数表 vtable，表中按固定顺序存虚函数地址。
每个对象头部有一个虚指针 vptr，指向所属类的 vtable；对象大小因此多一个指针。
存放位置：vtable 通常在只读数据段（.rodata / .data.rel.ro），不在对象里；对象里只有 vptr。
派生类覆盖虚函数会替换 vtable ；多继承时对象可能有多个 vptr。
构造/析构期间 vptr 会切换到当前类，所以构造/析构中调用虚函数不会派发到派生类

### 基类析构函数为什么要 virtual？
通过基类指针 delete 派生类对象时，若基类析构不是 virtual，只会调用基类析构，派生类部分不会析构
声明为 virtual 后，析构通过 vtable 动态分派到派生类，再自动调用基类析构，保证先派生后基类的完整析构。
