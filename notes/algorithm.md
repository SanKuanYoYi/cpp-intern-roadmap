136 只出现一次的数字
题目说：除一个元素只出现一次外，其余每个元素都出现两次。
O(1) 空间解法：异或运算。任何数异或自己 = 0	a ^ a = 0。任何数异或 0 = 自己	a ^ 0 = a

76 最小覆盖字串
利用 ASCII 码 128个。多个变量：need：清单，静态，构建后不变。needKinds：清单上有几种商品，静态。window：购物车，动态，随窗口变化。valid：购物车里已买齐的商品种类数，动态。判断覆盖：valid == needKinds
