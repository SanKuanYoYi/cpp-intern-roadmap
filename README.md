★phase01：{
一个基于 C++ 的简单控制台学生信息管理程序，支持增删改查、排序以及文件持久化。代码采用多文件结构，使用 CMake 构建。
--功能
添加学生（姓名、年龄、分数）、删除指定姓名的学生、修改指定学生的年龄和分数、按姓名查找学生、显示所有学生、按分数降序排序、保存学生数据到文件、从文件加载学生数据
--结构
student_manager/
├── CMakeLists.txt      # CMake 构建配置
├── head_files.h        # 头文件：类定义、函数声明、全局变量声明
├── main.cpp            # 程序入口，调用主菜单循环
├── student.cpp         # 各功能函数的具体实现
└── students.txt        # 数据文件（空格分隔：姓名 年龄 分数）
--环境要求
Linux 操作系统
CMake ≥ 3.10
支持 C++17 的编译器（如 g++ 7+）
}
